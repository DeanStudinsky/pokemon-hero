PMDCollab Pokemon Follow Sprites
=================================
Source: https://sprites.pmdcollab.org/

Format: {pokemon_id}-{variant}.png
  - b-n = back, normal
  - b-s = back, shiny
  - f-n = front, normal (female)
  - m-n = front, normal (male)

Atlas layout (from atlasdata.txt):
  4x4 grid per sprite sheet
  Rows: north(0-3), west(4-7), east(8-9), south(12-15)
  Each frame is one walking animation step

Currently 1178 sprite files covering ~550 Pokemon with variants.
